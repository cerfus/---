# Видео дефектов из Телеграма → папки по квартирам

Скрипт скачивает **все видео** из группы «Видео дефектов» и раскладывает их
по папкам с номерами квартир:

```
D:\Стекла\
├── 200\  кв200_2026-03-14_id1852.mp4
├── 201\  кв201_2026-03-14_id1857.mp4
├── 305\  ...
├── неопознанно\   ← сюда попадает то, где номер найти не удалось
├── _отчет.csv     ← таблица: что, откуда, какая квартира
└── _состояние.json ← чтобы при повторном запуске не качать заново
```

## Как скрипт узнаёт номер квартиры

По порядку, до первого попадания:

1. **Подпись к видео** в Телеграме — «Квартира 65 Об1 стп1,2 Об2 стп1».
2. **Имя файла** — `кв_305_дефект.mp4`.
3. **Соседнее сообщение** в чате — но только если оно однозначно относится
   к этому видео. Текст, зажатый между двумя видео, не засчитывается никому:
   непонятно, к какому он относится, а разложить не туда хуже, чем оставить
   в «неопознанно» — там видео хотя бы на виду.
4. **Достройка по соседней подписи** — главное, что вытягивает раскладку,
   см. ниже.
5. **Речь в видео** — только по ключу `--speech` и только для остатка.
   По умолчанию выключена: в видео дефектов номер обычно не проговаривают.
6. **Текст на кадрах** — по ключу `--ocr`.

## Достройка по подписям

Подпись перечисляет дефекты: «Об1 стп1,2 Об2 стп1» — это три стеклопакета,
и ровно три видео для этой квартиры снимут. Альбом в Телеграме несёт одну
подпись на всю пачку, поэтому остальные видео квартиры приходят без текста.

Скрипт этим пользуется:

- **вперёд** — видео без подписи после подписанного относятся к той же
  квартире, но не больше, чем обещано в подписи;
- **назад** — некоторые пишут подпись последним сообщением альбома, поэтому
  недостающие добираются из видео прямо перед подписью;
- счётчик в обе стороны ограничен числом дефектов, так что достройка не
  может уползти на соседнюю квартиру.

На реальном архиве из 97 видео это дало: 46 по текстам, 46 достроено,
5 осталось разбирать руками, перебора нет ни в одной папке.

Обещание даёт любой текст, который сам назвал квартиру, — и подпись видео,
и соседнее сообщение: дефекты перечислены и там, и там. Достроенные видео
обещаний не добавляют, иначе счёт задвоился бы и проверка показала бы
несуществующий перебор.

Отключается ключом `--no-spread`.

## Файлы-подсказки

Кроме `_отчет.csv` скрипт кладёт в `D:\Стекла` ещё два файла:

- **`_проверка.txt`** — где число видео не сошлось с обещанным в подписи.
  Это и есть места, где раскладка могла ошибиться.
- **`_подсказки.txt`** — для каждого видео из «неопознанно» показывает
  соседние квартиры и у какой из них недобор. Обычно этого хватает, чтобы
  разложить остаток не глядя видео.

Если ничего не нашлось — видео уходит в папку `неопознанно`, а в `_отчет.csv`
видно, что именно было слышно в ролике, чтобы разложить руками.

## Быстрый старт

1. Скачать все файлы этой папки в одну папку на компьютере, например `D:\скрипт\`.
2. Установить Python с https://www.python.org/downloads/ —
   **обязательно с галочкой «Add Python to PATH»**.
3. Запустить **`Установить.bat`** — он сам поставит библиотеки и ffmpeg.
4. Запустить **`Проба.bat`** — скачает 10 последних видео. При первом
   запуске скрипт сам спросит `api_id` и `api_hash` и подскажет, где их
   взять (см. ниже). Введёшь один раз — запомнит в `config.ini`.
5. Проверить `D:\Стекла\_отчет.csv` — верно ли определились квартиры.
6. Если всё верно — **`Запустить.bat`** на весь архив.

### Где взять api_id и api_hash

1. Открыть https://my.telegram.org
2. Ввести номер телефона в виде `+7...`
3. **Код придёт не в СМС, а сообщением в самом Телеграме** — от «Telegram».
4. Нажать **API development tools**.
5. App title и Short name — любые, например `steklo`. Platform — Desktop,
   описание можно не заполнять. Нажать **Create application**.
6. На странице появятся `App api_id` (число) и `App api_hash` (длинная
   строка) — их и вводить.

Файл `config.ini` с этими ключами и файл `tg_defects_session.session` —
личные, они равносильны доступу к твоему аккаунту. Никому не пересылай.

### Если my.telegram.org пишет ERROR

Сайт отвечает голым «ERROR» почти на любую заминку. По убыванию частоты:

1. **Перезагрузи страницу** и снова зайди в *API development tools* —
   приложение часто создаётся несмотря на ошибку, и ключи уже там.
2. **Short name занят** — он уникален на весь Телеграм. Возьми что-то своё,
   например `steklo7412kv`. Нужно 5–32 символа, только латиница и цифры.
3. **Русские буквы в полях** — везде только латиница, включая Description.
4. **App title** — от 3 до 32 символов.
5. **VPN, прокси, блокировщик рекламы** — отключить, попробовать в другом
   браузере или в режиме инкогнито.

Если сайт так и не поддался — есть путь вообще без ключей, ниже.

## Видео скачаны вручную, подписей нет

Так выходит, когда видео сохраняли из чата по одному: рядом с ними нет ни
переписки, ни номеров квартир. Взять номер автоматически неоткуда — но и
пересматривать каждое видео не нужно, номера видно в самом чате.

**Шаг 1** — собрать список (`Список - шаг 1 собрать.bat` или):

```
python by_list.py --from "C:\Users\Вы\Desktop\авп"
```

Появится `_список.csv`: все видео **в порядке чата**, колонка «квартира»
пустая. Порядок важен — видео одной квартиры идут подряд.

Две вещи скрипт делает сам:

- **Убирает повторные скачивания.** Если качали пачками внахлёст, появятся
  файлы вида `видео (1).mp4` — тот же ролик, сохранённый дважды. В список
  попадёт только один. Если у копий разная длина, значит это всё-таки разные
  видео — тогда оставит обе и скажет об этом.
- **Восстанавливает порядок чата.** Мессенджеры называют файлы номерами
  сообщений (`20191026154145.mp4`), а номера растут со временем. Если все
  имена такие, список идёт по ним. Иначе — по времени съёмки из самого видео.

Время файла на диске в колонку не ставится: это момент скачивания, а не
съёмки, и ориентироваться на него нельзя.

**Шаг 2** — открыть список в Excel и проставить номера:

| в клетке «квартира» | что значит |
|---|---|
| число (`60`, `кв 65`) | эта квартира |
| пусто | та же квартира, что строкой выше |
| `нет` | в «неопознанно», квартиру сверху не наследовать |

Заполнять надо только **первую строку каждой квартиры**. Для сотни видео это
два десятка чисел, а не сто.

```
№;файл;снято;длительность;квартира
1;video_0001.mp4;2026-08-05 19:04;0:42;60
2;video_0002.mp4;2026-08-05 19:05;0:38;
3;video_0003.mp4;2026-08-05 19:06;0:51;
4;video_0004.mp4;2026-08-05 19:14;0:33;65
5;video_0005.mp4;2026-08-05 19:15;0:47;
```

Писать можно и «65», и «кв 65» — цифры возьмутся сами.

### Если в начале видео показывают табличку с номером

Тогда номера можно прочитать прямо с кадра — `Список - шаг 1 с табличками.bat`
или:

```
python by_list.py --from "C:\Users\Вы\Desktop\авп" --ocr
```

Скрипт достаёт три кадра из первых секунд, находит на них табличку и читает
число. Занимает около 5 секунд на видео.

**Число принимается, только если распознано уверенно.** Tesseract сам
оценивает свою уверенность, и порог стоит достаточно высоко (75 из 100):
где не уверен — в списке появится `нет`, и видео уйдёт в «неопознанно».
Так задумано: пустую папку видно сразу, а видео, тихо уехавшее в чужую
квартиру, находится только при разборе дефектов.

На тестовых роликах из 5 табличек уверенно прочиталось 4, ошибочных номеров
не было ни одного. На ваших табличках соотношение будет другим — посмотрите
колонку «как прочитано» в списке, там для каждого видео написано, что
получилось.

Порог можно сдвинуть: `--confidence 60` прочитает больше, но начнёт
ошибаться; `--confidence 90` — только совсем очевидное.

Для этого нужен **Tesseract**:

```
winget install UB-Mannheim.TesseractOCR
pip install pytesseract Pillow numpy
```

При установке Tesseract стоит отметить русский язык (Russian), но это не
обязательно: без него скрипт читает только цифры, а для таблички с числом
этого достаточно — он скажет об этом и продолжит.

`winget` ставит Tesseract, но не всегда прописывает его в PATH. Скрипт сам
ищет его в обычных местах установки, так что отдельно настраивать ничего не
нужно. Если чего-то не хватает совсем, он скажет, чего именно, и соберёт
список без номеров.

**Шаг 3** — разложить (`Список - шаг 2 разложить.bat` или):

```
python by_list.py --from "C:\Users\Вы\Desktop\авп" --sort
```

## Выгрузка из другого мессенджера (MAX и прочие)

Скрипт читает не только выгрузку Телеграма. Если мессенджер отдаёт папку с
видео и текстовый лог переписки (`.txt`, `.csv`), раскладка работает так же:

```
python sort_export.py --from "C:\Users\Вы\Downloads\Экспорт MAX"
```

Лог распознаётся по строкам вида `[05.08.2026, 19:04] Имя: текст`, а видео
находится по имени файла, упомянутому в строке. Строка без файла считается
подписью к следующим видео — ровно как подпись альбома в Телеграме, и так же
ограничена числом дефектов.

Если в логе другой формат и скрипт напишет «узнал 0 видео из лога» — пришли
первые строки файла, формат добавится.

## Запасной путь: без api_id, через выгрузку из Телеграма

Телеграм умеет выгружать видео сам, без всяких ключей. Тогда скрипт только
раскладывает уже скачанное.

1. В **Telegram Desktop** (программа на компьютере, не телефон) открыть
   группу «Видео дефектов».
2. Три точки справа сверху → **Экспорт истории чата**.
3. Снять все галочки, оставить только **«Видеофайлы»**.
4. Формат — **JSON** или **HTML**, подписи читаются из обоих. Размер файла
   поднять до максимума.
5. Нажать «Экспортировать» и дождаться конца — получится папка вида
   `ChatExport_2026-09-09`.
6. Запустить **`Разложить выгрузку.bat`** и указать путь к этой папке.

Про что стоит знать заранее:

- Телеграм иногда отвечает, что экспорт будет доступен **через 24 часа** —
  это защита, срабатывает если недавно был вход с нового устройства.
  Ждать придётся, обойти нельзя.
- Выгрузка идёт долго и медленно: Телеграм намеренно режет скорость.
  Оставь её на ночь.
- Если размер файла в настройках экспорта выставлен маленьким, крупные
  видео не выгрузятся. Двигай ползунок вправо до упора.
- Для этого пути `telethon` не нужен — если он не встал при установке,
  ничего страшного.

Результат тот же: `D:\Стекла\200\`, `D:\Стекла\неопознанно\` и отчёт.
Если места на диске в обрез, добавь ключ `--move` — файлы будут
переноситься, а не копироваться:

```
python sort_export.py --from "C:\Users\Вы\Downloads\ChatExport_2026-09-09" --move
```

## Установка вручную (если `Установить.bat` не сработал)

1. **Python** — https://www.python.org/downloads/ — при установке
   обязательно поставить галочку **«Add Python to PATH»**.
2. **ffmpeg** — нужен, чтобы слушать звук из видео.
   Проще всего в PowerShell: `winget install Gyan.FFmpeg`
   (либо скачать с https://www.gyan.dev/ffmpeg/builds/ и добавить в PATH).
3. Библиотеки — в папке со скриптом выполнить:
   ```
   pip install -r requirements.txt
   ```
4. **api_id и api_hash**: зайти на https://my.telegram.org → *API development
   tools* → создать приложение (название любое). Оттуда взять `api_id`
   (число) и `api_hash` (длинная строка).

## Запуск

Впиши `api_id` и `api_hash` в файл `Запустить.bat` и запусти его двойным
кликом. Либо из командной строки:

```
python download_defects.py --api-id 1234567 --api-hash abcdef... ^
       --chat "Видео дефектов" --out "D:\Стекла"
```

При первом запуске Телеграм спросит номер телефона и пришлёт код
подтверждения — это обычный вход в твой аккаунт, пароль от Телеграма
никуда не уходит. Дальше вход запоминается в файле `tg_defects_session.session`
(держи его при себе, он равносилен доступу к аккаунту).

## Полезные ключи

| Ключ | Зачем |
|---|---|
| `--list-chats` | показать список групп с их id, если название не находится |
| `--limit 10` | попробовать на 10 последних сообщениях, прежде чем качать всё |
| `--whisper-model medium` | точнее распознавать речь (медленнее; варианты: `tiny`, `base`, `small`, `medium`, `large-v3`) |
| `--seconds 60` | слушать не 40, а 60 секунд начала видео |
| `--no-speech` | вообще не распознавать речь — только подписи и имена файлов (быстро) |
| `--ocr` | дополнительно читать номер с кадров (нужен Tesseract + `pip install -r requirements-ocr.txt`) |
| `--redo-unknown` | заново прогнать то, что лежит в `неопознанно` (например, уже с `--whisper-model medium`) |

## Что стоит знать

- **Прерывать можно смело.** Уже скачанное записано в `_состояние.json`,
  повторный запуск продолжит с того же места и не будет качать заново.
- **Первый запуск с распознаванием речи долгий** — модель Whisper
  (примерно 0,5 ГБ для `small`) скачивается один раз.
- **Проверь `_отчет.csv`.** В колонке «как определено» видно, откуда взялся
  номер. Строки с «речь в видео» имеет смысл выборочно перепроверить —
  распознавание речи иногда ошибается, особенно если на объекте шумно.
- Если видео уже лежит в папке, второй файл с тем же именем не затрётся —
  добавится `(2)`.

## Если в чёрном окне вместо русского букв каша

Файлы `.bat` сохранены в кодировке **CP866** — именно в ней `cmd` читает
батники. Если открыть такой файл в Блокноте и сохранить заново, Блокнот
переведёт его в UTF-8, и `cmd` начнёт ругаться `is not recognized as an
internal or external command`.

Что делать:
- правь `.bat` в **Notepad++** (Кодировки → Кириллица → OEM 866) или в
  Блокноте сохраняй через «Сохранить как» → Кодировка: **ANSI**;
- либо вообще не правь батники, а запусти скрипт руками:
  ```
  set TG_API_ID=1234567
  set TG_API_HASH=abcdef0123456789
  python download_defects.py --limit 10
  ```

На саму работу это не влияет: в командах внутри батников русских букв нет,
портится только текст подсказок на экране.

## Если распознавание речи ругается на cublas64_12.dll

Полный текст ошибки выглядит так:

```
! Ошибка распознавания речи: Library cublas64_12.dll is not found or cannot be loaded
```

Распознавание попыталось пойти через видеокарту, а библиотек CUDA на
компьютере нет. Скрипт теперь сам замечает это, переходит на процессор и
запоминает выбор в `config.ini`, так что при следующих запусках лишней
попытки уже не будет.

На процессоре медленнее — примерно 5–15 секунд на видео. Для сотни роликов
это 15–25 минут, приемлемо. Если хочется быстрее:

- `--whisper-model tiny` — заметно быстрее, но чаще ошибается на номерах;
- `--no-speech` — вообще без распознавания, только подписи и имена файлов
  (мгновенно, но много уедет в «неопознанно»).

Принудительно выбрать устройство можно ключом `--device cpu` или
`--device cuda`.

## Разумный порядок для большого архива

1. Сначала быстрый прогон без распознавания — разложатся все, у кого есть
   подпись или номер в имени файла:
   ```
   python sort_export.py --no-speech
   ```
2. Потом добить остаток распознаванием речи:
   ```
   python sort_export.py --redo-unknown
   ```

Так не придётся ждать распознавания для видео, где номер и так известен.

## Проверка по числу окон

В квартире столько видео, сколько окон — обычно 4. Это удобная сцепка для
поиска ошибок: если в папке 5 видео, одно туда попало чужое; если 3 — одно
потерялось в «неопознанно» или уехало к соседям.

Сводка печатается сама в конце раскладки и лежит в `D:\Стекла\_проверка.txt`.
Отдельно её можно получить в любой момент — `Проверка - по 4 видео.bat`
или:

```
python check_folders.py
python check_folders.py --per-flat 6     # если окон другое количество
```

Выглядит так:

```
Проверка: в каждой квартире ожидается по 4 видео
Квартир найдено:        24
  ровно по 4:           21
  меньше чем 4:         2
      46 (3), 305 (1)
  больше чем 4:         1
      200 (5)
В папке «неопознанно»:  6
```

Порядок разбора: сначала папки с перебором — из них лишнее переложить;
потом «неопознанно»; в конце папки с недобором. Номер квартиры для каждого
файла и то, откуда он взялся, видно в `_отчет.csv`.

Проверку можно отключить ключом `--per-flat 0`.

## Подкатегории окон

Скрипт различает только квартиры, но не окна внутри них: «левое большое»,
«правое» и прочее в имя папки не попадает. Все видео квартиры лежат в одной
папке, различить их можно по времени съёмки в имени файла.

## Если видео в папках больше, чем было в выгрузке

Так бывает, когда папку `Стекла` удаляли не до конца или потерялся файл
`_состояние.json`: скрипт не видит, что эти видео уже разложены, и кладёт
их заново рядом. Строка «Всего видео разложено» тогда больше, чем
«Нашёл видео».

Скрипт теперь такое замечает сам: если в папках лежат видео, а памяти о них
нет, раскладка останавливается и не делает хуже. Надёжный выход —
**`Разложить заново с нуля.bat`** (`python sort_export.py --clean`): он
стирает папки квартир и служебные файлы и собирает раскладку заново из
выгрузки. Сами видео лежат в выгрузке, так что потерять ничего нельзя.

Если же удалять всё не хочется, лишние копии можно вычистить точечно.

Скрипт помнит в `_состояние.json`, куда положил каждое видео. Всё, чего в
этой памяти нет, — след прежнего прогона:

```
python check_dupes.py            только показать
python check_dupes.py --delete   удалить лишнее
```

Удаляются только неучтённые файлы, нужные остаются на местах. Сверка идёт
по месту внутри раскладки («папка/имя файла»), а не по полному пути, так что
папку `Стекла` можно переносить и переименовывать.

Если память почти ни с чем не совпала — значит она не про эту папку (рядом
лежит чужой `_состояние.json`). Тогда скрипт отказывается удалять что-либо
и предлагает разложить заново: без верной памяти отличить лишнее от нужного
нельзя, а ошибка тут стоит всего архива.

Имей в виду: `_отчет.csv` дописывается, а не перезаписывается, так что в нём
копятся строки всех прогонов. Для каждого видео смотри последнюю строку.

## Видео не открывается: ошибка 0xC00D36C4

«Не удается открыть… тип этого файла не поддерживается, неверное расширение
либо файл повреждён» — чаще всего дело не в файле. Айфон снимает в **HEVC
(H.265)**, а встроенный «Медиаплеер» Windows такое без отдельного платного
расширения не открывает.

Проверить, в чём дело:

```
python check_videos.py           быстро, по заголовкам
python check_videos.py --deep    раскодирует каждое видео целиком
```

Скрипт покажет кодеки и отдельно — по-настоящему битые файлы.

- **Кодек `hevc`, битых нет** — поставь [VLC](https://videolan.org),
  он бесплатный и открывает всё. Проблема только в плеере.
- **Файл в списке битых** — он не докачался при выгрузке, забери его из
  Телеграма заново.
