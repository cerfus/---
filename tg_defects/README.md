# Видео дефектов из Телеграма → папки по квартирам

Скрипт скачивает **все видео** из группы «Видео дефектов» и раскладывает их
по папкам с номерами квартир:

```
D:\Стекла\
├── 200\  кв200_2026-03-14_id1852.mp4
├── 201\  кв201_2026-03-14_id1857.mp4
├── 305\  ...
├── неопознанно\   ← сюда попадает то, где номер найти не удалось
├── _отчет.csv     ← таблица: что, откуда, какая квартира
└── _состояние.json ← чтобы при повторном запуске не качать заново
```

## Как скрипт узнаёт номер квартиры

По порядку, до первого попадания:

1. **Подпись к видео** в Телеграме — «Квартира 200, трещина».
2. **Имя файла** — `кв_305_дефект.mp4`.
3. **Речь в начале видео** — распознаётся первые 40 секунд, ловится и
   «квартира 200», и «квартира двести пятьдесят три».
4. **Текст на кадрах** в начале видео (только с ключом `--ocr`).
5. **Соседнее сообщение** в чате рядом с видео.

Если ничего не нашлось — видео уходит в папку `неопознанно`, а в `_отчет.csv`
видно, что именно было слышно в ролике, чтобы разложить руками.

## Быстрый старт

1. Скачать все файлы этой папки в одну папку на компьютере, например `D:\скрипт\`.
2. Установить Python с https://www.python.org/downloads/ —
   **обязательно с галочкой «Add Python to PATH»**.
3. Запустить **`Установить.bat`** — он сам поставит библиотеки и ffmpeg.
4. Открыть https://my.telegram.org → *API development tools* → создать
   приложение, забрать оттуда `api_id` и `api_hash`.
5. Вписать их в `Проба.bat` и `Запустить.bat` (строки `set TG_API_ID=` и
   `set TG_API_HASH=`).
6. Запустить **`Проба.bat`** — скачает 10 последних видео, проверишь по
   `D:\Стекла\_отчет.csv`, верно ли определились квартиры.
7. Если всё верно — **`Запустить.bat`** на весь архив.

Файлы:

| Файл | Зачем |
|---|---|
| `Установить.bat` | поставить всё нужное (один раз) |
| `Проба.bat` | пробный прогон на 10 видео |
| `Запустить.bat` | скачать весь архив группы |
| `Список чатов.bat` | если группа по названию не находится |

## Установка вручную (если `Установить.bat` не сработал)

1. **Python** — https://www.python.org/downloads/ — при установке
   обязательно поставить галочку **«Add Python to PATH»**.
2. **ffmpeg** — нужен, чтобы слушать звук из видео.
   Проще всего в PowerShell: `winget install Gyan.FFmpeg`
   (либо скачать с https://www.gyan.dev/ffmpeg/builds/ и добавить в PATH).
3. Библиотеки — в папке со скриптом выполнить:
   ```
   pip install -r requirements.txt
   ```
4. **api_id и api_hash**: зайти на https://my.telegram.org → *API development
   tools* → создать приложение (название любое). Оттуда взять `api_id`
   (число) и `api_hash` (длинная строка).

## Запуск

Впиши `api_id` и `api_hash` в файл `Запустить.bat` и запусти его двойным
кликом. Либо из командной строки:

```
python download_defects.py --api-id 1234567 --api-hash abcdef... ^
       --chat "Видео дефектов" --out "D:\Стекла"
```

При первом запуске Телеграм спросит номер телефона и пришлёт код
подтверждения — это обычный вход в твой аккаунт, пароль от Телеграма
никуда не уходит. Дальше вход запоминается в файле `tg_defects_session.session`
(держи его при себе, он равносилен доступу к аккаунту).

## Полезные ключи

| Ключ | Зачем |
|---|---|
| `--list-chats` | показать список групп с их id, если название не находится |
| `--limit 10` | попробовать на 10 последних сообщениях, прежде чем качать всё |
| `--whisper-model medium` | точнее распознавать речь (медленнее; варианты: `tiny`, `base`, `small`, `medium`, `large-v3`) |
| `--seconds 60` | слушать не 40, а 60 секунд начала видео |
| `--no-speech` | вообще не распознавать речь — только подписи и имена файлов (быстро) |
| `--ocr` | дополнительно читать номер с кадров (нужен Tesseract + `pip install -r requirements-ocr.txt`) |
| `--redo-unknown` | заново прогнать то, что лежит в `неопознанно` (например, уже с `--whisper-model medium`) |

## Что стоит знать

- **Прерывать можно смело.** Уже скачанное записано в `_состояние.json`,
  повторный запуск продолжит с того же места и не будет качать заново.
- **Первый запуск с распознаванием речи долгий** — модель Whisper
  (примерно 0,5 ГБ для `small`) скачивается один раз.
- **Проверь `_отчет.csv`.** В колонке «как определено» видно, откуда взялся
  номер. Строки с «речь в видео» имеет смысл выборочно перепроверить —
  распознавание речи иногда ошибается, особенно если на объекте шумно.
- Если видео уже лежит в папке, второй файл с тем же именем не затрётся —
  добавится `(2)`.

## Если в чёрном окне вместо русского букв каша

Файлы `.bat` сохранены в кодировке **CP866** — именно в ней `cmd` читает
батники. Если открыть такой файл в Блокноте и сохранить заново, Блокнот
переведёт его в UTF-8, и `cmd` начнёт ругаться `is not recognized as an
internal or external command`.

Что делать:
- правь `.bat` в **Notepad++** (Кодировки → Кириллица → OEM 866) или в
  Блокноте сохраняй через «Сохранить как» → Кодировка: **ANSI**;
- либо вообще не правь батники, а запусти скрипт руками:
  ```
  set TG_API_ID=1234567
  set TG_API_HASH=abcdef0123456789
  python download_defects.py --limit 10
  ```

На саму работу это не влияет: в командах внутри батников русских букв нет,
портится только текст подсказок на экране.
